26° Comando: man

Comando man

O comando man fornece um manual completo para todos os comandos ou utilitários que podem ser executados no Terminal, incluindo o nome, a descrição e as opções.

Ele consiste em nove seções: 1. Programas executáveis ou comandos do shell / 2. Chamadas de sistema / 3. Chamadas da biblioteca / 4. Jogos / 5. Arquivos especiais / 6. Formatos e convenções de arquivos / 7. Comandos de administração do sistema / 8. Rotinas do kernel / 9. Diversos.

Para exibir o manual completo, digite:

man [nome_do_comando]
