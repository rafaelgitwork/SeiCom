## 📖 Sobre o projeto

O Projeto | Linux Shell Experience** é uma apresentação web interativa e temática, criada para introduzir conceitos de **Linux, terminal e shell** de maneira visual, acessível e envolvente.

Com uma estética inspirada em interfaces de linha de comando, efeitos de digitação e animações no estilo *Matrix*, o projeto reúne páginas explicativas e uma sequência de conteúdos sobre o universo dos sistemas operacionais e seus comandos.

A proposta é aproximar estudantes iniciantes de assuntos técnicos por meio de uma experiência mais dinâmica do que uma apresentação convencional.

## 🎓 Contexto acadêmico

Desenvolvido por estudantes do **Centro Universitário UDC** para a **Semana Integrada de Computação (SEICOM)**, o projeto foi apresentado a alunos do **1º e 2º períodos** da área de tecnologia.

O trabalho une aprendizado técnico, criatividade e comunicação para introduzir noções de ambiente Linux e de interfaces de linha de comando.

## ✨ Destaques

| Recurso | Descrição |
|:--|:--|
| 🖥️ **Visual de terminal** | Identidade inspirada em interfaces Linux e ambientes de linha de comando. |
| 🟢 **Efeito Matrix** | Animações visuais que reforçam a atmosfera tecnológica. |
| ⌨️ **Animações e interação** | Efeitos e navegação conduzidos por JavaScript. |
| 📚 **Conteúdo didático** | Introdução ao shell, diferenças entre terminal e shell, história e conceitos relacionados. |

## 🚀 Como executar

**1. Clone o repositório:**

```bash
git clone https://github.com/rafaelgitwork/SeiCom.git
```

**2. Acesse a pasta:**

```bash
cd SeiCom
```

**3. Abra `seicom.html` no navegador.**

Você também pode abrir a pasta em um editor de código, como o VS Code, e utilizar uma extensão de servidor local, como o **Live Server**, se preferir.

> **Dica:** a página `seicom.html` é a capa inicial da apresentação.
