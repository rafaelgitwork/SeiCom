Terminal vs. Shell

O Terminal

O Terminal (também conhecido como emulador de terminal, console ou janela de terminal) é o programa que você usa para acessar o shell. Ele fornece a interface visual e o ambiente onde você digita os comandos. Pense no terminal como a janela, a tela e o teclado, enquanto o shell é o motor por trás dele.

O Shell

Como já vimos, o shell é o intérprete de linha de comando. Ele é o programa que processa e executa os comandos que você digita no terminal. O shell é o cérebro que entende o que você quer fazer e traduz suas instruções para o sistema operacional.

Exemplos de Shells

Embora o terminal seja apenas a "janela", o shell pode ser trocado. Os mais comuns são:
- Bash: O shell padrão na maioria das distribuições Linux e macOS, conhecido por ser robusto e amplamente compatível. - Zsh: Uma versão mais moderna do Bash, com recursos avançados de autocompletar e temas. - Outros: Existem muitos outros shells, como o Fish, que se destaca por sua facilidade de uso e recursos interativos.
